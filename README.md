# СтройКонтроль — прототип первой версии

Адаптивное React + TypeScript веб-приложение для демонстрационного строительного проекта. Основной сценарий проверки: Windows + браузер Chrome/Edge, включая эмуляцию мобильных размеров экрана.

## Что потребуется на Windows

1. Установить Node.js версии 20 или новее (рекомендуется LTS): https://nodejs.org/
2. Распаковать архив `stroykontrol-prototype.zip` в удобную папку, например `C:\Projects\stroykontrol`.
3. Открыть эту папку в Проводнике.
4. В адресной строке Проводника набрать `cmd` и нажать Enter — откроется командная строка в папке проекта.
5. Выполнить команды:

```bash
npm install
npm run dev
```

6. Открыть адрес, который Vite покажет в терминале (обычно `http://localhost:5173`). Пока окно терминала открыто, приложение доступно в браузере.
7. Для остановки нажать `Ctrl+C` в терминале.

## Проверка мобильной ширины и высоты

В Chrome или Edge:

1. Открыть приложение.
2. Нажать `F12`.
3. Включить режим устройства кнопкой с изображением телефона/планшета или сочетанием `Ctrl+Shift+M`.
4. Выбрать готовую модель телефона либо задать ширину и высоту вручную.
5. Проверить портретную и альбомную ориентацию, прокрутку и доступность элементов.

Это эмуляция размеров и части сенсорного поведения в браузере. Окончательные жесты на реальном смартфоне следует отдельно проверить на устройстве.

## Текущий объём прототипа

- Демонстрационный проект «Строительство частного жилого дома».
- 8 этапов и 30 подработ.
- Табличная часть с подрядчиками, прогрессом, оплатой и бюджетом.
- Сворачивание/разворачивание этапов.
- Шкала Ганта с масштабами по дням, неделям и месяцам, маркером текущей даты и переходом к нему.
- Карточка работы и быстрый ввод прогресса/комментария.
- Адаптивная компоновка для смартфона: компактная колонка названий + отдельная прокручиваемая шкала Ганта.
- На мобильном бюджеты и оплаты скрыты из таблицы и доступны в карточке работы.
- Независимое приближение/отдаление шкалы и синхронная прокрутка строк и временной шкалы.
- На десктопе навигация перенесена наверх, боковая панель убрана, строки уплотнены.

## Публикация на GitHub Pages

В проект добавлен workflow `.github/workflows/deploy.yml`. Чтобы опубликовать сайт:

1. Создайте пустой репозиторий на GitHub, например `stroykontrol`.
2. Загрузите в него содержимое этой папки (папку `stroykontrol` целиком не вкладывайте внутрь ещё одной папки). Основная ветка должна называться `main`.
3. В репозитории откройте **Settings → Pages** и выберите **GitHub Actions** в качестве источника публикации.
4. Откройте вкладку **Actions**. Workflow `Deploy to GitHub Pages` соберёт приложение и опубликует его.
5. После успешного завершения GitHub покажет адрес сайта в разделе **Settings → Pages**. Обычно он имеет вид `https://<ваш-логин>.github.io/<имя-репозитория>/`.

При каждом следующем push в `main` сайт будет обновляться автоматически. В `vite.config.ts` задан относительный `base: './'`, чтобы статические ресурсы корректно открывались в подкаталоге GitHub Pages.

## Исправление прокрутки в v0.1.2

Вертикальная прокрутка теперь принадлежит общему контейнеру `.gantt-layout`, который прокручивает обе колонки как одну таблицу. Внутри него список работ больше не создаёт отдельную вертикальную область прокрутки, а `.timeline-body` отвечает только за горизонтальную прокрутку временной шкалы. Это устраняет рассинхронизацию двух независимых `scrollTop` и позволяет вертикальному свайпу на мобильном устройстве прокручивать весь график.

## Версия 0.1.3 — обновление графика Ганта

- Редактирование названия, дат начала/окончания, бюджета, оплаты, организации, численности бригады, прогресса и комментария в карточке работы.
- Статус, длительность и остаток рассчитываются автоматически и не редактируются вручную.
- Вертикальная прокрутка общая для списка работ и графика; колесо мыши над графиком прокручивает строки, горизонтальная прокрутка временной шкалы работает через Shift+колесо или горизонтальный скролл тачпада.
- На телефоне вертикальный свайп перемещает строки, горизонтальный свайп — даты.
- Бюджет и процент выполнения отображаются внутри полосы Ганта.
- Добавлены чекбоксы выбора работ, выбор всех видимых работ, удаление одной или нескольких работ.
- Уточнены подписи дней, недель и месяцев, чтобы они не накладывались друг на друга.

Изменения по-прежнему хранятся только в состоянии страницы и сбрасываются после перезагрузки. Для постоянного хранения потребуется подключить базу данных.


## Обновления интерфейса v0.1.4

- Удаление работ доступно через режим «Редактировать»: чекбоксы появляются только после его включения; выбор и удаление находятся в верхней панели графика.
- У каждого этапа постоянно отображается кнопка «+». Она открывает отдельную форму добавления работы с названием, датами, бюджетом, организацией и численностью бригады. Кнопка «Добавить» находится внизу формы.
- Добавлена кнопка разворачивания Ганта на весь экран. На мобильных устройствах приложение запрашивает альбомную ориентацию, если браузер и режим запуска это поддерживают; в остальных случаях экран можно повернуть вручную.
- Вертикальная прокрутка теперь принадлежит общей области графика: список и временная шкала движутся вместе. Колесо мыши над временной шкалой прокручивает строки, Shift+колесо или горизонтальное движение тачпада — даты; на сенсорном экране поддерживаются вертикальный и горизонтальный жесты.
